# Amazon Lightsail

- Amazon Lightsail is a bit of an oddball in AWS because it is kind of a stand-alone service.
- With Lightsail, you can get virtual servers, storage, databases, and networking in one place.
- It gives you low and predictable pricing.
- People use Lightsail because it is a much simpler alternative to using services such as EC2,RDS,ELB,EBS,Route53 and so on. 
- Lighsail is for people that have little cloud experience and don't want to learn how the services work intricately for example, how their networking works, how the storage works , how the server works etc.
- From lighsail , you can also set up some monitoring, notifications for your lightsail resources
- Use cases:-
    - If you want to deploy a very simple web application . For example, if you have LAMP Stack, Nginx, MEAN stack, Node.js. There is templates for that on Lightsail
    - You have very simple website for example , if you have Wordpress, Magento, Plesk, Joomla. All these kinds of things can be deployed very easily on Lightsail.
    - Lightsail is great if you have development and test environment in AWS
- There is a concept of **high availability** in Lightsail but there is **no auto-scaling** and there are **limited AWS integrations**
