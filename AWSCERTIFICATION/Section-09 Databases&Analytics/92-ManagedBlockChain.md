# Amazon Managed Blockchain

- Blockchain makes it possible to build applications where multiple parties can execute transactions without the need for trusted central authority.
- So there's a decentralization aspect to a Blockchain . 
- Managed Blocked by Amazon is a service to join a public Blockchain networks or create your own scalable private Blockchain network within AWS.
- It's compatible with two Blockchain so far. The framework Hyperledger Fabric(private) and the framework Ethereum(public)


- So in simple terms: It is a distributed database stored across many servers (nodes). Blockchain makes sure all those servers agree on the same entries without needing a central authority.
