# DocumentDB

- The same way we had Aurora as the way for AWS to implement a sort of big cloud native version of PostgreSQL and MySQL, We have **DocumentDB**, which is an Aurora version for MongoDB
- It is a NoSQL database and it's based on top of the MongoDB technology. So it's compatible with MongoDB. 
- MongoDB is used to store query and index JSON data. 
- You have the same similar deployment concepts as Aurora with DocumentDB
- It's a fully managed database, highly available. Data is replicated across three availability zones. 
- DocumentDB storage automatically will grow in increments of 10 Gigabytes.
- DocumentDB has been engineered as it can scale to workloads with millions of requests per second
