# AWS CodeCommit 

- Before pushing the application code to servers, you need to store it somewhere
- Developers usually choose a code repository, usually that was going to be backed using the **GIT** technology
- And a very famous public offering is called **GitHub** but AWS has a competing product that is going to be **CodeCommit**
- So CodeCommit is a way for you to store your code within AWS in a version control repository.
    - So it is going to be for **Git-based repository**
    - Once you have git-based repository , it becomes incredibly easy for developers to collobrate with each other on the code. 
    - The code changes are going to be automatically versioned and can be rolled back
- Benefits of CodeCommit:
    - You have a fully-managed code repository
    - Scalable and high available
    - It lives within your AWS accounts so it is private , secure and integrated with all AWS services
